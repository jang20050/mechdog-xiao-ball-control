학습 순서

  1. "빨간 공 학습"을 고르고 화면 속 빨간 공을 클릭하세요. 거리·각도·조명을 바꿔 가며 3~5번 클릭하면 더 잘 인식해요.
    또는 공만 보여 주고 YOLO 자동 학습을 누르세요.
  2. 파란 공도 같은 방법으로 학습하세요. 파란 공은 학습하기 전에는 인식하지 않아요(잘못 전진하지 않도록).
  3. "인식 화면"에서 공만 색칠되는지 확인하세요. 배경이 칠해지면 채도·밝기를 올리세요.
  4. 저장을 눌러야 XIAO 전원을 꺼도 유지돼요.

빨간 공 → 정지

파란 공 → 전진

최소 크기
공이 이 픽셀 수(160×120 중)보다 크게 보여야 인식해요. 멀리서도 인식하려면 낮추세요.
